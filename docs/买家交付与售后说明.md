# 买家交付与售后说明

本说明适用于本项目的商业授权版。最终授权范围以订单中勾选的 `LICENSE.md` 为准。

## 交付内容

购买商业授权版后，买家将收到：

1. 完整源代码（前端、后端、数据库迁移与种子数据）；
2. Cloudflare 与腾讯 CloudBase 两套部署说明；
3. 九个接口级冒烟测试脚本，可在自己的部署环境复验；
4. 演示账号、部署安装手册与本授权协议；
5. 品牌配置文件，替换品牌名称无需修改业务代码。

交付包不包含云服务账号、域名、短信/支付服务、微信小程序、自动排课算法及未写明的定制功能。

## 商业授权版的服务边界

- 授权对象：一个法人主体及其直营校区；可为自营业务二次开发。
- 不包含：将源码、修改版或部署后的系统转售、转授权、公开分发或作为多租户 SaaS 提供给第三方。
- 支持内容：部署文档范围内的问题定位、已有功能的使用答疑与缺陷复现确认。
- 不包含的支持：新增功能、第三方账号/网络故障、数据迁移、品牌视觉设计、业务流程重构。这些按独立报价处理。
- 建议响应承诺：工作日 24 小时内首次响应。实际支持期限与渠道以订单和 `LICENSE.md` 填写内容为准。

## 交付流程

1. 买家确认授权档位、部署目标和品牌信息；
2. 卖方确认付款与授权信息；
3. 发送带版本号的源码交付包和授权协议；
4. 买家按部署手册完成首次启动并运行冒烟测试；
5. 买家在约定验收期内反馈可复现问题，卖方按授权范围处理。

## 部署加购服务

部署服务是一次性加购，不属于默认源码交付：

- 基础部署：部署到买家自有 Cloudflare 或 CloudBase 账号，建议报价 800 元起；
- 品牌配置：替换名称、Logo 和主色，建议报价 500 元起；
- 域名、云资源、备案和第三方服务费用由买家自行承担；
- 托管仅按年度单独报价。除非订单明确包含，不承诺长期运行维护或数据备份。

## 验收与退款

源码属于可复制的数字交付物。建议先看演示并确认功能边界；交付后因“改变主意”或未阅读功能限制，不适用退款。若在约定验收期内能复现交付包无法按部署手册启动的问题，卖方应优先修复或协商处理。任何退款承诺以交易平台规则和订单约定为准。
